# GemShopTrixBot — نسخه ۱

نسخه اول ربات فروشگاه جم TRIX شامل:

- /start
- عضویت اجباری در کانال
- بررسی عضویت
- منوی اصلی
- دکمه خرید جم
- دکمه پیگیری سفارش
- دکمه پشتیبانی
- تنظیمات جداگانه در فایل `.env`

## 1) نصب Python

Python 3.10 یا جدیدتر پیشنهاد می‌شود.

## 2) نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

## 3) ساخت فایل تنظیمات

فایل `.env.example` را به `.env` تغییر نام دهید.

سپس این موارد را در `.env` وارد کنید:

```env
BOT_TOKEN=توکن_واقعی_ربات
CHANNEL_GUID=GUID_کانال
SHOP_USERNAME=@TRIX__SHOP
SHOP_LINK=https://rubika.ir/TRIX__SHOP
```

توکن را داخل کد `main.py` نگذارید و آن را در اختیار دیگران قرار ندهید.

## 4) اجرای ربات

```bash
python main.py
```

## نکته مهم درباره CHANNEL_GUID

کتابخانه Rubka برای بررسی عضویت از `check_join(channel_guid, chat_id)` استفاده می‌کند و مستندات آن می‌گوید ربات باید در کانال ادمین باشد.

بنابراین `CHANNEL_GUID` باید شناسه داخلی کانال باشد، نه صرفاً `@TRIX__SHOP`.

اگر هنوز GUID کانال را ندارید، در مدیریت بات/اطلاعات کانال دنبال شناسه داخلی کانال بگردید یا آن را از روش رسمی/API مورد استفاده خودتان دریافت کنید. مقدار نمونه `c0xABCDEF...` را وارد نکنید.

## نسخه‌های بعدی

بعد از اینکه این نسخه با موفقیت اجرا شد، می‌توانیم همین پروژه را توسعه دهیم و اضافه کنیم:

1. بسته‌های جم و قیمت‌های قابل ویرایش
2. دریافت Player ID
3. نمایش شماره کارت
4. دریافت تصویر رسید
5. ثبت سفارش در SQLite
6. ارسال سفارش و رسید برای مدیر
7. تأیید/رد سفارش توسط مدیر
8. پیام وضعیت سفارش به مشتری
9. پنل مدیریت قیمت‌ها و متن‌ها
10. پشتیبان‌گیری از سفارش‌ها

ساختار پروژه عمداً ساده و ماژولار نگه داشته شده تا این تغییرات بعداً بدون بازنویسی کل ربات انجام شوند.
